## PRAY: the Game

## Main concept

RPG top down view game about the 3 heroes that surviving in post apocalipsis against alien worms where most of the population get’s into harmless zombified incubators for the aliens.

## Gameplay

Top-down game, mouse clicks move the characters like in RPG. Environment is static if character(s) does not move. You have an option to set up pause, plan the movement for the characters and release the pause for simultaneous movement.  
Characters has abilities that is unknown and discovered once the characters move forward

## Story

Story moments injected in a comic style photos where player can check the next comic and so on.
