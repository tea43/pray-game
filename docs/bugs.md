## Status of the bug
 - Status of the bug is written in square brackets
 - Possible statuses
    - TBD = not yet started
    - IPG = in progress
    - VAL = done avaiting manual validation
    - FAL = failed the manual verification, fix does not work.
    - DON = done and validated but not yet commited

## File usage
 - Take the first bug
 - Mark the bug fix as in progress
 - Once bug fixed and verified: mark the bug fixed
 - Commit the fix
 - Remove the bug from the list
